## Program Description

This program demonstrates Dart variables, data types, arithmetic operators, comparison operators, and console output through a simple store purchase calculator.

## Data Types Used

- int: Stores the quantity of items.
- double: Stores the unit price and total price.
- String: Stores the customer's name.
- bool: Stores the customer's membership status and comparison result.

## Operators Used

- * : Multiplies the quantity by the unit price.
- > : Checks whether the total price is greater than PHP 500.
- ~/ : Performs integer division.
- % : Calculates the remainder.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal in the project folder.
3. Run `dart run`.
